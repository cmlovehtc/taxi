# 計程車考照 Android 0.2.0

以目前發布網站 v71（88cbb0e9c0a290f5f889a173335047556c2d5b98）為考試設定與題解來源。

- 原生 Android Activity / Views，沒有 WebView；題目、分類、解析、記憶法皆可離線使用。
- 標準卷：20 題是非 + 30 題選擇，60 分鐘，70 分及格。自訂題數不限時，離開保留剩餘時間。
- 22 報考縣市的個別比例，支援只練單一縣市及進階輸入比例；依每個題型先取整數再隨機補齊。
- 每題解析、題库對照、相近題、5 縣市記憶法、主題篩選、答案排序、單純模式與閱讀位置；移除收藏介面。
- 每次開啟自動檢查題庫，只以 manifest.updated_at 判斷新內容。成功確認或更新後顯示「已更新到官方最新題庫」，來源只顯示警政署。時間以 Asia/Taipei 顯示。
- 題庫 SHA-256 驗證後才原子替換；解析依當前題目內容對照，已變動的證據不沿用舊解析。
- 同 package/versionCode 2，沿用 0.1.0 測試簽章，保留本機學習資料。

## 建置與驗證

`bash android-app/build.sh`（Android SDK 35、Build Tools 35.0.0、JDK17）。

`tools/export-web-data.mjs <published-site-checkout>` 直接執行網站原始函式，匯出規則/記憶法/人工核對資料及 6610 題比對雜湊，不包裝網站。

GitHub Actions 編譯並在 Android 15 模擬器測試：安裝更新、完整題庫解析與網頁一致性、20/30 題與配比、自訂題數、成績、閱讀介面及紀錄保存。

仍是測試 APK，未送 Google Play。網站帳號/雲端同步、試卷 PDF、3D 車庫與地圖功能尚未移植；本版沿用既有本機平面車庫。
