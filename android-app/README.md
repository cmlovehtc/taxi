# 計程車考照 Android 測試版

獨立 Android 原生 App。Java + Android 系統元件，不使用 WebView、不載入網站畫面，也不下載執行程式碼。題庫來源沿用本 repository 的 TXT 與 `question-bank-manifest.json`。

## 0.1.0 功能

- 內建完整題庫，五縣市與交通法規可離線練習及模擬考。
- 可選報考地區、五縣市 60/10/10/10/10 配比、是非／選擇題數、考試分鐘數；任一題型可設定 0。
- 即時練習回饋、計時模擬考、題號總覽、未答題跳轉、關閉後繼續作答。
- 題庫搜尋、全國地區篩選、每頁 30 題、點卡片展開答案、收藏、閱讀位置、錯題複習。
- 成績紀錄、首次答對獎勵、每日 5 題挑戰、免費車色及用金幣購買六種配件的平面車庫。
- 夜間模式、字級調整、以 Android 檔案選擇器匯出與還原 JSON 學習紀錄。
- HTTPS 題庫更新、SHA-256 完整性比對、格式與數量驗證、原子寫入；更新中或失敗時保持可離線作答。
- 只申請網路權限；沒有廣告、登入、分析追蹤或作答紀錄上傳。

此版不含網站的帳號同步、網路排行榜、後台統計、地圖記憶圖片、PDF 出卷及 3D 車內視角，這些功能尚待獨立移植。金幣僅供本機練習使用。

## 安裝

將 `taxi-exam-0.1.0.apk` 下載至 Android 8.0 以上手機並開啟。若系統詢問，允許本次使用的瀏覽器或檔案管理員安裝此 APK。套件名稱為 `tw.cmlove.taxiexam.preview`，與未來正式版分開。此為可偵錯的測試簽署版本，非 Google Play 正式發行版。

學習紀錄儲存在 App 私有空間；移除 App 前請在「我的」匯出備份。更新 APK 須使用相同套件與測試簽署金鑰，勿用正式上架金鑰替換這份測試 APK。正式上架將另行設定正式簽署、關閉偵錯與政策資料。

## 編譯與驗證

需要 JDK 17、Android SDK platform 35、build-tools 35.0.0。從 repository 根目錄執行 `bash android-app/build.sh`。測試工作流程只在 Android 開發分支觸發，不會部署或更新網站。

輸出 APK 已經 zipalign 並使用 apksigner 簽署。workflow 保存 APK、完整性雜湊、原生題庫邏輯測試報告及 Android 模擬器的操作截圖。測試簽署金鑰使用獨立 GitHub Actions cache 保留；cache 不等同永久金鑰備份。

題庫更新只讀取 `https://cmlovehtc.github.io/taxi/` 的 manifest 與指定題庫文字檔。題目識別碼以題目內容與答案計算，避免題庫插入新題後導致錯題錯位；進行中的測驗使用完整題目快照。

資料來源：內政部警政署公開題庫。本 App 是獨立練習工具，不代表政府機關。實際試題及考試規定以主管機關公告為準。
